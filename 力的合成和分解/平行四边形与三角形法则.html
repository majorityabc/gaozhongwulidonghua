力的合成与分解：平行四边形法则与三角形法则

从同一作用点 O 画出两个分力，以它们为邻边作平行四边形，过 O 的对角线就是合力 R（浅色箭头为对边的平移复制）
|F₁|： 50N |F₂|： 40N 夹角 θ： 60° 也可以直接拖动 F₁、F₂ 的彩色端点
平行四边形法则
F₁ = 50 N（蓝色，方向水平）
F₂ = 40 N（绿色）
两力夹角 θ = 60°
R = √(F₁²+F₂²+2F₁F₂cosθ)
R = 78.1 N
R 与 F₁ 的夹角 φ = 26.3°
步骤：① 从作用点 O 画出 F₁、F₂；② 以它们为邻边补全平行四边形（对边就是分力的平移复制）；③ 从 O 出发的对角线即合力 R。两个分力张得越开，对角线越短，合力越小。
平行四边形被对角线 R 分成两个全等三角形——每个三角形里都有 F₁、F₂、R 三个力。点按钮把其中一个分力平移过去，拼出三角形
|F₁|： 50N |F₂|： 40N 夹角 θ： 60°
从平行四边形到三角形
F₁ = 50 N　F₂ = 40 N　θ = 60°
R = 78.1 N（两个三角形里是同一条边）
发现：求合力其实不必画完整的平行四边形——只要把两个分力首尾相接，从第一个力的起点指向第二个力的终点的那条边就是合力。两种接法（F₁ 后接 F₂、F₂ 后接 F₁）得到同一个合力。这就是三角形法则。
