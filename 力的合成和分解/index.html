力的合成与分解

F₁ = 30 N、F₂ = 50 N 大小保持不变，夹角 θ 从 0° 转到 360°：合力大小在 |F₁−F₂| 与 F₁+F₂ 之间变化
夹角 θ： 90° θ = 0°（即 360°）时两力同向，合力最大；θ = 180° 时两力反向，合力最小
合力随夹角的变化
F₁ = 30 N（蓝色，固定）
F₂ = 50 N（绿色，固定）
夹角 θ = 90°
合力 R = √(F₁²+F₂²+2F₁F₂cosθ)
R = 58.3 N
R 的方向（与 F₁ 夹角）φ = 59.0°
结论：两分力大小不变时，合力大小只随夹角变化：θ=0°（即360°）时两力同向，R = F₁+F₂ = 80 N 最大；θ=180° 时两力反向，R = |F₁−F₂| = 20 N 最小；|F₁−F₂| ≤ R ≤ F₁+F₂。θ 与 360°−θ 的合力大小相等，方向关于 F₁ 对称。
R 随 θ 变化的曲线（红点为当前状态）
合力 F = 60 N 竖直向下且保持不变；两个分力以 F 为轴对称，各与 F 成角 θ。θ 越大，分力越大
分力与合力的夹角 θ： 30° 两分力夹角为 2θ；θ 接近 90° 时分力趋于无穷大（本演示取 θ ≤ 75°）。播放时每经过 15° 会留下一个灰色历史平行四边形，便于前后对比
对称分解：分力随夹角变化
合力 F = 60 N（竖直向下，红色）
θ = 30°（分力与合力夹角）
两分力夹角 2θ = 60°
由对称性 F₁ = F₂，且 2F₁cosθ = F
F₁ = F₂ = F / (2cosθ)
F₁ = F₂ = 34.6 N
结论：合力一定时，两个对称分力的夹角越大，分力就越大；夹角越小，分力越接近合力的一半（F/2 = 30 N）。这就是"晾衣绳绷得越平，绳上拉力越大"的道理。
分力大小随 θ 变化的曲线（红点为当前状态）
合力 F = 60 N 大小方向不变；分力 F₂ 方向不变（与 F 夹角 30°）；分力 F₁ 大小可调、方向可变——用滑块改变 |F₁|，看力的三角形与平行四边形的解
|F₁|： 45N 以 F 末端为圆心、|F₁| 为半径作圆，圆与 F₂ 方向射线的交点决定解的个数；也可以直接用手（或鼠标）拖动交点的彩色圆点，沿 F₂ 方向滑动来改变 |F₁|
解的个数讨论
合力 F = 60 N（水平向右）
F₂ 方向：与 F 成 30°（不变）
F·sin30° = 30 N（|F₁| 的最小值）
|F₁| = 45 N
规律：|F₁| < F·sin30° 时无解；|F₁| = F·sin30° 时唯一解（F₁⊥F₂）；F·sin30° < |F₁| < F 时两解；|F₁| ≥ F 时只有一解。绿色箭头为 F₂，蓝色/青色箭头为 F₁，红色为合力 F；细虚线为平行四边形的补线。
